# v0.0.2 - OpenAI Codex OAuth hotfix

## Features

- **Kimi K3 support** - the Kimi Coding provider now offers Kimi K3 and K3-256K with their full reasoning and context-window capabilities.

## Improvements

- None.

## Bug Fixes

- **OpenAI Codex OAuth works after packaged updates** - Pi-backed ChatGPT/Codex sessions no longer fail with `OAuth auth derivation failed for openai-codex: Cannot find module './openai-codex.js'` in the AppImage. The Pi subprocess now registers the SDK's bundled Bun OAuth flows before model runtime creation, so lazy OAuth auth derivation uses the embedded `openai-codex` flow instead of trying to load a missing sibling file next to the single-file bundle.
- **Visible shared-profile startup conflict** - Mkrate now shows an actionable native error and exits cleanly when another Craft/Mkrate process owns the shared profile, instead of leaving an invisible background process.

## Breaking Changes

- None.

# v0.0.1 — Initial Mkrate Desktop Release

## Initial release

- **Mkrate identity and attribution** — Introduces Mkrate Desktop as an independent Apache-2.0 fork of Craft Agents, preserving required attribution and compatibility internals while presenting the Mkrate product name to users.
- **Kimi K3 and agent runtime** — Ships the Mkrate desktop agent experience with Kimi K3 support and the existing Craft Agents Backend compatibility layer for proven local agent execution.
- **Trusted Bridge v1** — Includes the audited Trusted Bridge v1 Desktop runtime for self-hosted mobile/desktop connectivity, with Desktop remaining authoritative for sessions, credentials, files, tools, execution, and replay.
- **Multi-platform desktop assets** — Supports Linux x64 AppImage, macOS arm64/x64 DMG and ZIP assets, and Windows x64 installer assets for the first public binary set.
- **Compatibility identifiers preserved** — Hidden functional identifiers remain intentionally unchanged, including `@craft-agent/*`, `CRAFT_*`, `CRAFT_AGENTS_DOWNLOAD_BASE_URL`, `~/.craft-agent`, `craftagents://`, `x-scheme-handler/craftagents`, protocol/tool IDs, and `Craft Agents Backend`.
- **Unsigned binary disclosure** — All v0.0.1 desktop binaries are unsigned. macOS artifacts are also unnotarized, so users should expect normal platform security warnings for this initial release.
